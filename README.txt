MODULE 5 RESPONSIVE NAVIGATION DELIVERABLE

Site Name:
Princess Donut's Royal Companions

Purpose: A fictional animal shelter that cares for unwanted pets and finds them homes.

Navigation:
Page navigation consists of a skip link that is hidden until focus that moves to main content, a brand link that navigates to the home page, and a responsive navigation menu with the following links: Home, Find A Pet, Visit, Support Us, Contact Us. When the page size reaches a specific breakpoint the navigation menu toggles from a horizontal menu to a collapsed menu that is activated using a button labeled Menu.

Required Files:
- index.html, pets.html, visit.html, support.html, contact.html: html structure for the website
- styles.css : shared styling
- navigation.js: minimal behavior scaffold
- navigation-plan.html: planning, testing, code-defense, and AI evidence
- README.txt: site description and project information
- nojs-320p-breakpoint.png : screenshot proof for navigation-plan
- narrow-menu-wide-hover-no-css.png : screenshot proof for navigation-plan

Use:
1. Extract all items from the folder and save to a local folder.
2. Open index.html to view the page.
3. Open navigation-plan.html in another tab to view documentation.
4. Testing can be done via your browser's specific developer tools.

Notes:
Breakpoint between wide view and narrow view is based off your browser's standard font size (for Chrome this is 16pt). For standard Chrome Browsers it occurs at 1088px (68rem) when viewed at 100%. 

This project uses relative file paths. Ensure each file name matches the list above before accessing the project files.
